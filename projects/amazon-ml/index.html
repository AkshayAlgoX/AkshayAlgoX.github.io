Team Duty_Drive · entity resolution

Amazon ML Challenge 2026

My team’s experiment harness and entity-resolution pipeline for linking records about the same business.

View the code

Harness reproducible from the repo · competition data not redistributable

The problem

The task was entity resolution: deciding which records, from different sources, describe the same real-world business, across about 1.7 million query records from India, the US and France. Comparing every record with every other is out of the question, so the system has to find likely candidates first.

My part in the team

We were a team of three. I led the systems side: the shared harness everyone built on, the retrieval (candidate generation) work, and the “ein” track of experiments. Teammates owned other modelling tracks, so this page doesn’t claim the whole system as mine.

Why the metric shaped everything

Scoring used macro F0.5 per entity. With β = 0.5 a false positive costs four times as much as a missed match, so confident wrong links were the expensive mistake. That pushed the design toward high-recall candidate generation followed by a careful, precision-first decision with an explicit option to abstain.

The pipeline

Records are normalised (accents, abbreviations), then several blocking lanes propose candidates: exact name and address anchors, character and word TF-IDF, geographic street-and-number blocks, and rare-token or postal blocks. A cheap model prunes early, richer features and a cross-encoder rerank what’s left, a LightGBM ranker scores pairs, and a threshold tuned for F0.5 plus conflict resolution produce the final links.

Inference ran as 17 country shards on Kaggle, which had to fit its session time and memory limits.

The harness

Everyone’s experiments shared the same folds, metric code, experiment log and submission validator, so results were comparable across teammates. The public repository runs this harness and a synthetic end-to-end pipeline from a clean clone (18 tests). The specialised entity-resolution code lives on a competition branch, and the full run needs the competition data, which can’t be redistributed.

Result

Team Duty_Drive finished at public leaderboard rank #1,200 with a score of 0.978758. The Unstop result page isn’t publicly linkable, so I can show it on request.
