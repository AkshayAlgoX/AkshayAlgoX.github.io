SettleMate AI

A reconciliation tool that matches payments to invoices and uses an LLM only to investigate the exceptions.

Why it’s tricky. A convincing explanation isn’t the same as a correct total.

What I did. An LLM investigator drafts structured claims about each exception, and a rule-based validator checks every number and reference against the records. The matching itself stays in integer paise and an exact branch-and-bound search.

TypeScript · LLM APIs · PostgreSQL · Prisma

Runs locally · hosted demo offline

Buy or Wait?

Rank #85 of 3,062 · score 68.2 / 100

A Python engine that decides whether a purchase should be paid now, split into payments, or postponed.

Why it’s tricky. A purchase can fit today’s balance and still make next month’s rent impossible.

What I did. Messages and receipt images can go through an LLM extractor, but it may only return typed facts that are validated before use. A suffix-minimum search over the projected balance then finds the earliest safe payment day.

Python · Decimal · Constraint search

Gumora

A marketplace where creators sell digital products through Cashfree checkout and buyers download from a personal library.

Why it’s tricky. A “success” redirect isn’t proof that money moved, and confirmations can arrive twice.

What I did. Settlement re-checks the order with Cashfree, then marks it paid and counts the sale in one MongoDB transaction, so a repeated confirmation changes nothing.
